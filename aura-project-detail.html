Sound made
visible

Most music players are transport mechanisms — press play, music comes out. Aura was conceived as a different proposition: what if the visual layer was as carefully designed as the audio layer? The waveform scrubber, frequency visualiser, and spatial indicator aren't decorations — they're playback controls in disguise.

The Web Audio API exposes raw frequency data at 60fps. The challenge was making that data beautiful without making it distracting — a visualisation that responds to the music's actual emotional texture, not just its amplitude.

"Music listeners close their eyes. The interface should work in the periphery — present when you want it, invisible when you don't."

Built as a React PWA with a custom Web Audio analyser, Canvas-rendered frequency bars, and GSAP-driven gesture animations. The spatial audio controls use device gyroscope data to create a genuinely immersive listening experience beyond anything currently on the market.

Challenges

Frequency,
frame rate, feeling

🎵
60fps Audio Sync
Web Audio API delivers FFT data every ~23ms at 44.1kHz. Rendering this to Canvas at 60fps without dropped frames required a custom requestAnimationFrame loop decoupled from the React render cycle — visual state lives in a ref, not component state.
🤚
Gesture Vocabulary
A music player controlled by gestures needs a vocabulary that doesn't conflict with native scroll. Horizontal swipes scrub time, vertical swipes control volume, two-finger rotation adjusts spatial balance — none conflict with browser defaults.
🔊
Spatial Audio Model
Used the Web Audio API's PannerNode and device gyroscope to approximate binaural positioning — the stereo field shifts as you rotate the phone, placing instruments at different perceived distances without requiring native HRTF support.
01
Real-Time Frequency Visualiser
512-band FFT analysis rendered to Canvas at 60fps. Bar heights, colours, and opacity map to different frequency ranges — bass as width, mids as height, highs as luminosity. The result reads the emotional register of the music, not just its loudness.

Tools & Stack

Built on
the Web Audio stack

React
Component-driven UI with custom hooks for Web Audio context management and gesture state.
🎵
Web Audio API
AnalyserNode for FFT, PannerNode for spatial audio, GainNode for volume — all connected in a custom audio graph.
🎨
Canvas 2D
OffscreenCanvas for pre-rendered waveform, requestAnimationFrame loop for live frequency bars at 60fps.
✨
GSAP
Gesture feedback animations, track transition sequences, and the loading visualiser.
📱
Device APIs
Gyroscope and touch event APIs for spatial audio control and swipe gesture recognition.
🎧
PWA
Service worker caching for offline playback; manifest for add-to-home-screen with full-screen mode.
🔷
TypeScript
Fully typed audio graph, gesture handler, and Canvas renderer — zero runtime type errors.
🧪
Testing
Vitest unit tests for the audio graph logic; Playwright e2e for gesture interaction flows.
