Calm by
design

Most wellness apps prioritise feature density over feeling. They're cluttered, gamified, and ironically stressful to navigate. Luminary started from a single constraint: every interaction should feel like exhaling. That principle shaped every decision from colour temperature to animation curve selection.

The brief called for an iOS app that guided users through personalised breathing programs and sleep sessions. The challenge was designing an interface that could be used in the dark, half-asleep, or mid-panic attack — and still feel intuitive on the first touch.

"An app about calm should never make you think. Every gesture, every transition, every colour choice should work with your nervous system — not against it."

The result is a 60fps interaction system built in Protopie, a hand-illustrated asset library, and a design system built around biometric states — awake, transitioning, and resting. Each state has its own colour temperature, animation speed, and typographic rhythm.

Challenges

Designing for
distressed states

🌑
Dark Mode First
The primary use case is a user in bed at 11pm. The entire colour system was built with dark mode as the default — light mode is a secondary derivation. Every elevation, every contrast ratio, every glow was tested at minimum brightness.
🌊
60fps Spring Physics
Easing curves that feel mechanical break the illusion of calm. Every transition uses custom spring parameters (stiffness 180, damping 20) tuned to feel like water — resistance without abruptness. Prototyped at native frame rate in Protopie, not just Figma.
✍️
Custom Illustration
Stock icons felt clinical. All 34 session illustrations were drawn as a cohesive system — organic forms, muted palettes, and a consistent line weight that works at every size from the app icon down to a 16px tab bar glyph.
01
Spring Animation System
Every interactive element in Luminary uses a custom spring physics model. Sliders snap with satisfying weight, modals unfurl like fabric, and the breathing orb expands and contracts on a sine curve matched to the human inhale-exhale cycle.
