Motion as
language

A fintech brand approached the project with a UI library built in React but no motion layer whatsoever. Every state change was instantaneous — modals appeared, notifications popped, data loaded, all without any transition. The interface felt clinical and untrustworthy for a product handling real money.

The brief was to create a motion design system comprehensive enough that engineers could implement it without further design input — a library of Lottie files, timing specs, easing curves, and usage guidelines that worked as a standalone handoff document.

"Good motion in a financial product isn't decorative — it tells users that their action was registered, their data is real, and the system is trustworthy."

The output was 200+ After Effects animations exported as Lottie JSON, a 48-page motion guidelines document, and an interactive web-based component previewer. Engineering implementation time for motion dropped by 60% compared to the team's previous approach.

Challenges

200 components,
one language

🎯
Systematic Consistency
200+ components must feel like they came from a single mind. Defined a master easing curve library, a duration scale (80ms, 160ms, 320ms, 640ms), and a directional grammar — every component's motion references shared values, never raw numbers.
📦
Lottie File Size
Lottie files balloon quickly with complex animations. A custom AE script strips unused layers before export — shape merging, expression simplification, keyframe reduction. Average file size dropped from 48KB to 11KB, critical for mobile bundle budgets.
⚡
Reduced Motion Support
Every animation in the system has a reduced-motion variant. The AE project uses a precomp naming convention (COMP_rmo) that generates two exports automatically — full animation and a static version for users with vestibular disorders.
01
Easing Curve Library
Five master curves cover every interaction type. Spring for interactive responses, ease-out for entrances, ease-in for exits, linear for data transitions. Each is defined as both a CSS cubic-bezier and an After Effects graph editor preset.
